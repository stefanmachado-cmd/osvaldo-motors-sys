# Osvaldo Motors System

## Cliente
Seu Osvaldo (Osvaldo Motors)

## Objetivo do Sistema
Desenvolver um sistema personalizado de gerenciamento automotivo focado em controle de clientes, manutenções e orçamentos.

## Requisitos Principais
- Distinguir três categorias de dados: dono, placa/modelo do veículo e nome do cliente.
- Exibir ao lado de cada pessoa o histórico de manutenção realizada e o orçamento necessário.
- Implementar uma tabela especial para carros de luxo aplicando um acréscimo de 20% no valor.
